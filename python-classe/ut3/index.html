    UT3 · Control de flujo y bibliotecas para administración¶

    Esta página reúne toda la teoría de la UT3. La tabla de contenidos permite saltar a cada apartado 3.1–3.5 y a sus subapartados.

    UT3 · 3.1 Condicionales: tomar decisiones¶

    Tomar decisiones en un programa¶

    Hasta ahora muchas instrucciones se ejecutaban de arriba abajo. Los condicionales permiten decidir qué bloque se ejecuta según una condición.

    edad = int(input("Edad: "))

if edad >= 18:
    print("Puedes acceder")

    La expresión edad >= 18 produce True o False. El bloque indentado solo se ejecuta cuando es verdadera.

    La indentación es obligatoria¶

    Python no utiliza llaves para delimitar bloques. La indentación forma parte de la sintaxis. La convención habitual es utilizar cuatro espacios.

    if edad >= 18:
    print("Mayor de edad")
    print("Acceso permitido")

    if, else y elif¶

    else se ejecuta cuando la condición del if no se cumple.

    if edad >= 18:
    print("Puedes acceder")
else:
    print("No puedes acceder")

    Cuando hay varias posibilidades utilizamos elif:

    nota = float(input("Nota: "))

if nota < 5:
    print("Suspenso")
elif nota < 7:
    print("Aprobado")
elif nota < 9:
    print("Notable")
else:
    print("Sobresaliente")

    Python evalúa las condiciones en orden. Cuando una se cumple, ejecuta ese bloque y no evalúa los siguientes bloques de la cadena.

    Operadores lógicos¶

    Podemos combinar condiciones con and, or y not.

    Operador Significado
    and deben cumplirse ambas condiciones
    or basta con que se cumpla una
    not niega una condición 
    edad = 20
tiene_entrada = True

if edad >= 18 and tiene_entrada:
    print("Puede entrar")

    dia = "sábado"

if dia == "sábado" or dia == "domingo":
    print("Fin de semana")

    es_laboral = False

if not es_laboral:
    print("Fin de semana")

    Evaluación en cortocircuito¶

    Con and, si la primera condición es False, Python no necesita evaluar la segunda. Con or, si la primera ya es True, tampoco necesita evaluar la segunda.

    x = 0

if x != 0 and 10 / x > 2:
    print("Se cumple")

    La división no llega a evaluarse cuando x vale cero.

    Paréntesis¶

    No son obligatorios alrededor de la condición:

    if edad >= 18:
    print("OK")

    Pueden mejorar la claridad en condiciones largas:

    if (edad >= 18 and tiene_entrada) or es_admin:
    print("Acceso permitido")

    Asignación condicional¶

    Python permite una asignación condicional sencilla:

    resultado = "apto" if nota >= 5 else "no apto"

    Equivale a un if/else que asigna uno de los dos valores. No conviene utilizar esta forma si hace el código difícil de leer.

    Valores verdaderos y falsos¶

    Algunos valores se comportan como falsos dentro de una condición, entre ellos:

    ""
0
[]
None

    Por ejemplo:

    nombre = input("Nombre: ").strip()

if nombre:
    print(f"Hola, {nombre}")
else:
    print("No has escrito nada")

    Ejemplo aplicado a sistemas¶

    espacio_libre_gb = 3

if espacio_libre_gb < 5:
    print("Aviso: queda poco espacio libre")
else:
    print("Espacio suficiente")

    Más adelante podremos obtener datos reales del sistema mediante librerías; la estructura de decisión será la misma.

    Errores frecuentes¶

    No confundas asignación y comparación:

    edad = 18     # asignación
edad == 18    # comparación

    Un if necesita : al final:

    if edad >= 18:
    print("OK")

    Y el bloque debe estar correctamente indentado.

    Comprueba que sabes...¶

    • Utilizar if, elif y else.
    • Entender que los bloques se definen por indentación.
    • Utilizar and, or y not.
    • Explicar la evaluación en cortocircuito.
    • Diferenciar = de ==.
    • Escribir una asignación condicional sencilla.
    • Saber que los paréntesis no son obligatorios en un if.
    • Reconocer valores vacíos que se comportan como falsos.

    Para el examen

    Lee una cadena de if/elif de arriba abajo: se ejecuta el primer bloque cuya condición sea verdadera.

    Fuente principal: material de clase Introducción a Python 3.1 · Condicionales.

    UT3 · 3.2 Bucles while¶

    Repetir mientras se cumpla una condición¶

    Un bucle permite repetir instrucciones. while repite un bloque mientras su condición sea verdadera y resulta útil cuando no sabemos de antemano cuántas repeticiones serán necesarias.

    contador = 1

while contador <= 5:
    print(contador)
    contador += 1

    Cada repetición se denomina iteración.

    Cómo funciona¶

    En cada vuelta Python evalúa la condición:

    1. Si es True, ejecuta el bloque.
    2. Al terminar, vuelve a comprobar la condición.
    3. Cuando es False, sale del bucle.

    Por eso debemos asegurarnos de que algo pueda hacer que la condición deje de cumplirse.

    Repetir una entrada de usuario¶

    clave = ""

while clave != "python":
    clave = input("Contraseña: ")

print("Acceso concedido")

    Este patrón permite repetir una pregunta hasta recibir el dato esperado.

    Bucles infinitos¶

    Este bucle nunca termina:

    contador = 1

while contador <= 5:
    print(contador)

    Falta modificar contador, así que siempre vale 1.

    También podemos utilizar voluntariamente while True, pero debe existir una forma de salir:

    while True:
    comando = input("Comando: ")

    if comando == "salir":
        break

    print(f"Ejecutando {comando}")

    break¶

    break termina inmediatamente el bucle.

    while True:
    texto = input("Escribe algo: ")

    if texto == "fin":
        break

    print(texto)

    Cuando el usuario escribe fin, la ejecución continúa después del bucle.

    continue¶

    continue salta directamente a la siguiente iteración.

    numero = 0

while numero < 5:
    numero += 1

    if numero == 3:
        continue

    print(numero)

    Salida:

    1
2
4
5

    Cuando numero vale 3 no se llega al print() de esa iteración.

    Cuidado con continue

    Antes de ejecutar continue, asegúrate de que las variables que controlan el bucle se actualizan. De lo contrario puedes crear un bucle infinito.

    while con else¶

    Python permite asociar un else a un while.

    contador = 1

while contador <= 3:
    print(contador)
    contador += 1
else:
    print("Bucle terminado sin break")

    El else se ejecuta cuando el bucle termina de forma normal porque la condición pasa a ser falsa. Si termina mediante break, el else no se ejecuta.

    contador = 1

while contador <= 3:
    if contador == 2:
        break

    print(contador)
    contador += 1
else:
    print("No se ejecuta")

    Validar una entrada¶

    Podemos combinar while con métodos de cadenas:

    edad = input("Edad: ")

while not edad.isdigit():
    print("Debes escribir un número")
    edad = input("Edad: ")

edad = int(edad)
print(f"Edad registrada: {edad}")

    Primero mantenemos el dato como cadena para comprobarlo. Cuando cumple la condición esperada, lo convertimos a entero.

    Ejemplo paso a paso¶

    Queremos pedir un número positivo hasta que el usuario escriba uno válido.

    numero = int(input("Número positivo: "))

while numero <= 0:
    print("El número debe ser mayor que cero")
    numero = int(input("Número positivo: "))

print(f"Número aceptado: {numero}")

    La variable se vuelve a actualizar dentro del bucle. Si olvidáramos la segunda lectura, una entrada negativa produciría un bucle infinito.

    Cuándo pensar en while¶

    Utiliza while cuando la repetición depende principalmente de una condición y no conoces necesariamente de antemano el número de iteraciones. Ejemplos del temario son repetir una contraseña o validar una entrada.

    Comprueba que sabes...¶

    • Explicar qué es una iteración.
    • Utilizar while con una condición.
    • Actualizar correctamente la variable que controla el bucle.
    • Detectar un posible bucle infinito.
    • Utilizar break.
    • Utilizar continue.
    • Entender cuándo se ejecuta el else de un while.
    • Validar una entrada de usuario mediante while.

    Para el examen

    Antes de ejecutar mentalmente un while, localiza tres cosas: valor inicial, condición y actualización.

    Fuente principal: material de clase Introducción a Python 3.2 · Bucles while.

    UT3 · 3.3 Bucles for, range() y recorridos¶

    Recorrer elementos¶

    El bucle for sirve para recorrer los elementos de un iterable: por ejemplo, cadenas, listas, rangos o líneas de un archivo.

    A diferencia de while, normalmente utilizamos for cuando conocemos el conjunto de elementos que queremos recorrer.

    Recorrer una cadena¶

    for letra in "Python":
    print(letra)

    Salida:

    P
y
t
h
o
n

    Una cadena es una secuencia y puede recorrerse carácter a carácter.

    Recorrer una lista¶

    alumnos = ["Ana", "Luis", "Marta"]

for alumno in alumnos:
    print(alumno)

    En este punto basta entender una lista como una colección ordenada de elementos dentro de una variable.

    range()¶

    range() genera un rango de números que se utiliza muy a menudo con for.

    for numero in range(5):
    print(numero)

    Salida:

    0
1
2
3
4

    El límite final no se incluye.

    Inicio y fin¶

    for numero in range(1, 6):
    print(numero)

    Recorre 1, 2, 3, 4, 5.

    Inicio, fin y paso¶

    for numero in range(1, 6, 2):
    print(numero)

    Salida:

    1
3
5

    La forma general es:

    range(inicio, fin, paso)

    Contar hacia atrás¶

    El paso puede ser negativo:

    for numero in range(2, -1, -1):
    print(numero)

    Salida:

    2
1
0

    Empieza en 2, resta 1 en cada iteración y se detiene antes de -1.

    range() no es una lista¶

    En Python 3, range() devuelve un objeto range.

    valores = range(5)
print(valores)
print(list(valores))

    Salida:

    range(0, 5)
[0, 1, 2, 3, 4]

    No necesitas convertir un range a lista para recorrerlo con for.

    Índice y valor con enumerate()¶

    Cuando necesitamos tanto el índice como el elemento, podemos utilizar enumerate():

    alumnos = ["Ana", "Luis", "Marta"]

for indice, alumno in enumerate(alumnos):
    print(indice, alumno)

    Salida:

    0 Ana
1 Luis
2 Marta

    Podemos indicar otro valor inicial:

    for indice, alumno in enumerate(alumnos, 1):
    print(indice, alumno)

    Ahora la numeración empieza en 1.

    _ cuando no necesitamos la variable¶

    Si queremos repetir una acción pero no utilizamos el valor del rango, es habitual escribir _:

    for _ in range(3):
    print("Repetir")

    El guion bajo es una convención que indica que ese valor no nos interesa.

    break en un for¶

    for numero in range(1, 10):
    if numero == 5:
        break

    print(numero)

    Salida:

    1
2
3
4

    break termina completamente el bucle.

    continue en un for¶

    for numero in range(1, 6):
    if numero == 3:
        continue

    print(numero)

    Salida:

    1
2
4
5

    continue solo salta el resto de la iteración actual.

    for con else¶

    Un for también puede tener else. El bloque else se ejecuta cuando el bucle termina normalmente, sin pasar por un break.

    El ejemplo del temario busca divisores:

    numero = 7

for divisor in range(2, numero):
    if numero % divisor == 0:
        print("No es primo")
        break
else:
    print("Es primo")

    Si se encuentra un divisor, break evita el else. Si se recorre todo el rango sin encontrarlo, se ejecuta else.

    Bucles anidados¶

    Un bucle puede estar dentro de otro:

    for fila in range(1, 4):
    for columna in range(1, 4):
        print(f"Fila {fila}, columna {columna}")

    El bucle interior se ejecuta completo por cada iteración del exterior. Hay que utilizarlos con cuidado porque el número de iteraciones se multiplica.

    Ejemplo aplicado a administración¶

    archivos = ["log1.txt", "foto.png", "log2.txt", "datos.csv"]

for archivo in archivos:
    if archivo.endswith(".txt"):
        print(f"Procesar {archivo}")

    Este patrón será habitual: recorrer elementos, comprobar una condición y actuar.

    for o while¶

    Como regla práctica basada en estos temas:

    • for: quieres recorrer un conjunto de elementos o un rango.
    • while: quieres repetir mientras se cumpla una condición y no necesariamente sabes cuántas iteraciones habrá.

    Comprueba que sabes...¶

    • Recorrer cadenas y listas con for.
    • Utilizar range(fin).
    • Utilizar range(inicio, fin).
    • Utilizar range(inicio, fin, paso).
    • Contar hacia atrás con un paso negativo.
    • Saber que range() no devuelve directamente una lista.
    • Utilizar enumerate() para obtener índice y valor.
    • Reconocer el uso convencional de _.
    • Utilizar break y continue.
    • Entender el else asociado a un for.
    • Leer bucles anidados.
    • Aplicar un for para recorrer nombres de archivos.

    Para el examen

    En range(inicio, fin, paso), fin nunca se incluye. Antes de responder, escribe a mano los primeros valores que produciría el rango.

    Fuente principal: material de clase Introducción a Python 3.3 · Bucles for, range() y recorridos.

    UT3 · 3.4 Depuración, errores y excepciones¶

    Equivocarse forma parte de programar¶

    Programar implica cometer errores. Lo importante es aprender a localizarlos, entender el mensaje que ofrece Python y corregirlos de forma ordenada.

    Tipos de errores¶

    Errores de sintaxis¶

    El código no respeta las reglas del lenguaje.

    if edad >= 18
    print("OK")

    Faltan los dos puntos y Python no puede ejecutar correctamente el programa.

    Errores en tiempo de ejecución¶

    El programa comienza a ejecutarse, pero falla durante la ejecución.

    numero = int("abc")

    Produce ValueError porque "abc" no puede convertirse a entero.

    Otros errores que puedes encontrarte al practicar son ZeroDivisionError, IndexError o NameError.

    Errores lógicos¶

    El programa se ejecuta sin lanzar una excepción, pero el resultado no es el esperado.

    precio = 100
iva = 21
precio_final = precio + iva

    Python puede ejecutar esas instrucciones, pero la fórmula puede no representar el cálculo que pretendíamos realizar.

    Los errores lógicos requieren revisar la lógica del programa porque Python no puede saber cuál era nuestra intención.

    Leer una traza¶

    Cuando Python falla, la traza contiene pistas. Fíjate especialmente en:

    • el tipo de error;
    • la línea indicada;
    • la última llamada de la traza;
    • el mensaje final.

    Ejemplo:

    ValueError: invalid literal for int() with base 10: 'abc'

    La pista principal es que se ha intentado convertir abc a entero.

    No empieces cambiando código al azar

    Primero identifica el tipo de error y la línea. Después revisa los valores que llegan a esa instrucción.

    Probar poco a poco¶

    El material recomienda no escribir muchas líneas antes de probar. Podemos inspeccionar valores temporalmente:

    edad = input("Edad: ")
print(f"DEBUG: {edad=}")

    La sintaxis {edad=} permite ver el nombre de la variable y su valor.

    Excepciones¶

    Una excepción es un evento anómalo durante la ejecución que interrumpe el flujo normal, por ejemplo una conversión inválida, una división por cero o un acceso incorrecto.

    El temario presenta las herramientas de manejo de excepciones para que sepamos que existen, aunque indica que no se utilizarán en profundidad en este módulo por considerarlas programación más avanzada.

    try y except¶

    Podemos capturar un error previsible:

    texto = input("Número: ")

try:
    numero = int(texto)
    print(numero * 2)
except ValueError:
    print("Debes escribir un número entero")

    No debemos utilizar try/except simplemente para ocultar errores que no entendemos. Primero hay que comprender qué operación puede fallar.

    raise¶

    raise permite lanzar explícitamente una excepción cuando detectamos una situación que consideramos inválida.

    edad = -5

if edad < 0:
    raise ValueError("La edad no puede ser negativa")

    assert¶

    assert permite comprobar una condición durante el desarrollo.

    edad = 20
assert edad >= 0

    Podemos añadir un mensaje:

    edad = -1
assert edad >= 0, "La edad no puede ser negativa"

    Si la condición es falsa, se produce AssertionError.

    Según el temario, las aserciones son útiles para detectar errores internos mientras desarrollamos; no deben entenderse como el mecanismo habitual para validar siempre los datos introducidos por un usuario.

    Depuración en VS Code¶

    VS Code permite utilizar puntos de interrupción y ejecutar el programa paso a paso. También podemos utilizar temporalmente mensajes de depuración:

    print(f"DEBUG: {variable=}")

    El objetivo es observar qué valores tiene el programa antes de la línea donde aparece el comportamiento inesperado.

    Estrategia de depuración¶

    El procedimiento propuesto en el material es:

    1. Reproduce el error.
    2. Lee la traza.
    3. Localiza la línea.
    4. Imprime o inspecciona variables.
    5. Prueba con un caso pequeño.
    6. Corrige y vuelve a probar.

    Ejemplo explicado¶

    texto = input("Edad: ")
print(f"DEBUG: {texto=}")
edad = int(texto)
print(edad + 1)

    Si escribimos abc, la conversión falla. En lugar de modificar varias líneas a la vez:

    1. observamos que el error es ValueError;
    2. localizamos int(texto);
    3. comprobamos con el mensaje DEBUG que texto contiene "abc";
    4. entendemos que el problema está en la conversión del dato recibido.

    Comprueba que sabes...¶

    • Diferenciar un error de sintaxis, uno de ejecución y uno lógico.
    • Localizar el tipo de error al final de una traza.
    • Utilizar mensajes sencillos de depuración.
    • Explicar para qué sirven try y except.
    • Reconocer un except ValueError.
    • Explicar para qué sirve raise.
    • Explicar para qué sirve assert.
    • Seguir un procedimiento ordenado de depuración.

    Para el examen

    Ante una traza, empieza por el tipo de error y el mensaje final. Después localiza la línea y comprueba los valores que estaba utilizando.

    UT3 · 3.5 Librerías útiles para administradores de sistemas¶

    De los ejercicios a pequeños scripts de administración¶

    Python incluye una biblioteca estándar amplia. Muchas herramientas ya vienen con Python y podemos utilizarlas mediante import.

    import platform

print(platform.system())

    El objetivo de este tema no es memorizar todas las funciones, sino saber qué librerías existen, importarlas, entender ejemplos sencillos y consultar documentación cuando sea necesario.

    Forma de importar utilizada en estos apuntes

    Para mantener una forma consistente y fácil de reconocer utilizaremos normalmente import modulo, por ejemplo import datetime y import pathlib. El material de clase también muestra importaciones concretas como from pathlib import Path; ambas formas existen, pero aquí priorizamos la primera.

    sys: intérprete y argumentos¶

    sys permite consultar información del intérprete y trabajar con los argumentos con los que se ha iniciado un script.

    import sys

print(sys.version)
print(sys.platform)

    Elementos importantes del temario:

    • sys.version: versión de Python.
    • sys.platform: plataforma.
    • sys.exit(): termina el programa.
    • sys.argv: argumentos recibidos en la línea de comandos.

    Argumentos de un script¶

    import sys

if len(sys.argv) < 2:
    print("Uso: python saluda.py nombre")
else:
    print(f"Hola, {sys.argv[1]}")

    Ejecución:

    python saluda.py Ana

    sys.argv[0] contiene el nombre del script y sys.argv[1] el primer argumento.

    os: sistema operativo y variables de entorno¶

    El temario presenta os para interactuar con el sistema operativo.

    import os

print(os.getcwd())
print(os.listdir("."))
print(os.getenv("PATH"))

    También dispone de operaciones como os.mkdir(). Para trabajar con rutas y directorios, el propio material recomienda utilizar normalmente pathlib, que ofrece una interfaz más moderna.

    datetime: fechas y horas¶

    Utilizaremos el módulo completo:

    import datetime

ahora = datetime.datetime.now()
print(ahora)

    La fecha actual puede obtenerse con:

    import datetime

hoy = datetime.date.today()
print(hoy)

    Sumar o restar tiempo¶

    import datetime

hoy = datetime.datetime.now()
ayer = hoy - datetime.timedelta(days=1)
print(ayer)

    strftime()¶

    Permite dar formato a una fecha:

    import datetime

hoy = datetime.datetime.now()
print(hoy.strftime("%Y-%m-%d"))

    Podemos crear un nombre de copia de seguridad:

    import datetime

hoy = datetime.datetime.now()
nombre_backup = f"backup_{hoy.strftime('%Y_%m_%d')}.zip"
print(nombre_backup)

    Hora y día de la semana¶

    import datetime

hora = datetime.datetime.now().hour

if hora < 14:
    print("Buenos días")
else:
    print("Buenas tardes")

    import datetime

dia = datetime.datetime.now().weekday()
print(dia)

    weekday() devuelve 0 para lunes y 6 para domingo.

    platform: información del sistema¶

    import platform

print("Sistema operativo:", platform.system())
print("Versión:", platform.release())
print("Procesador:", platform.processor())

    Podemos combinarlo con condicionales:

    import platform

if platform.system() == "Windows":
    print("Configurando entorno para Windows...")

    pathlib: rutas de forma moderna¶

    pathlib permite trabajar con rutas mediante objetos Path.

    import pathlib

ruta = pathlib.Path.cwd()
print(ruta)

    Operaciones y propiedades que aparecen en el material:

    Elemento Uso
    Path.cwd() directorio actual
    iterdir() recorrer elementos de un directorio
    exists() comprobar si existe
    is_dir() comprobar si es directorio
    is_file() comprobar si es archivo
    mkdir() crear directorio
    rmdir() eliminar directorio
    rename() renombrar
    stat() consultar información de la ruta
    suffix extensión final
    parent ruta padre

    Construir rutas¶

    import pathlib

ruta = pathlib.Path.cwd()
carpeta = ruta / "ejercicios"

if not carpeta.exists():
    carpeta.mkdir()
    print("Carpeta creada")
else:
    print("La carpeta ya existe")

    El operador / permite construir una ruta a partir de sus partes.

    Crear carpetas anidadas¶

    import pathlib

ruta = pathlib.Path("backups") / "2026" / "10" / "dia_29"
ruta.mkdir(parents=True, exist_ok=True)
print(ruta)
    • parents=True crea los directorios intermedios necesarios.
    • exist_ok=True evita un error si la carpeta ya existe.

    Consultar información de un archivo¶

    import pathlib

archivo = pathlib.Path("informe.log")

if archivo.exists():
    datos = archivo.stat()
    print(datos.st_size)
    print(datos.st_mtime)

    Recorrer una carpeta¶

    import pathlib

for elemento in pathlib.Path(".").iterdir():
    print(elemento.name)

    Filtrar por extensión¶

    import pathlib

for archivo in pathlib.Path(".").iterdir():
    if archivo.is_file() and archivo.suffix == ".py":
        print(archivo.name)

    Aquí se combinan objetos, métodos, for y if.

    shutil: operaciones de alto nivel con archivos¶

    El material introduce shutil para copiar, mover o eliminar archivos y carpetas y consultar el uso de disco.

    import shutil

    Funciones destacadas:

    • shutil.copy(origen, destino).
    • shutil.move(origen, destino).
    • shutil.rmtree(carpeta).
    • shutil.disk_usage(ruta).

    Copiar un archivo¶

    import pathlib
import shutil

origen = pathlib.Path("backup.zip")
destino = pathlib.Path("copias") / "backup.zip"

destino.parent.mkdir(exist_ok=True)

if origen.exists():
    shutil.copy(origen, destino)
    print("Backup copiado")

    Uso de disco¶

    import shutil

total, usado, libre = shutil.disk_usage("/")
porcentaje = usado / total * 100
print(f"Uso: {porcentaje:.2f}%")

    total, usado y libre están expresados en bytes.

    random y time¶

    El temario también utiliza estas librerías en algunos ejercicios:

    import random
import time

numero = random.randint(1, 100)
simbolo = random.choice("!#$%&*")

print(numero)
print(simbolo)
time.sleep(1)
    • random.randint(a, b) devuelve un entero entre ambos límites.
    • random.choice(secuencia) selecciona un elemento.
    • time.sleep(segundos) pausa la ejecución.

    zfill() para numeración¶

    Aunque no es una librería, el tema recuerda zfill() para generar nombres numerados:

    for numero in range(1, 4):
    print(str(numero).zfill(2))

    Salida:

    01
02
03

    glob() y rglob()¶

    pathlib permite buscar archivos mediante patrones.

    import pathlib

for archivo in pathlib.Path(".").glob("*.py"):
    print(archivo.name)

    Busca archivos .py en la carpeta actual.

    Para una búsqueda recursiva:

    import pathlib

for archivo in pathlib.Path(".").rglob("*.log"):
    print(archivo)

    Ejemplo integrador¶

    El ejemplo final combina conceptos de toda la unidad:

    import datetime
import pathlib
import platform

print(f"Sistema: {platform.system()}")
print(f"Fecha: {datetime.datetime.now():%Y-%m-%d}")

carpeta = pathlib.Path(".")
contador_py = 0

for archivo in carpeta.iterdir():
    if archivo.is_file() and archivo.suffix == ".py":
        contador_py += 1

print(f"Archivos Python encontrados: {contador_py}")

    Aquí aparecen:

    • variables;
    • condicionales;
    • bucles;
    • librerías;
    • rutas;
    • f-strings.

    Qué debes memorizar y qué no¶

    El material indica expresamente que no tienes que memorizar todas las funciones de estas librerías. Lo importante es:

    • saber que existen;
    • saber importarlas;
    • saber utilizarlas;
    • reconocer ejemplos;
    • consultar documentación;
    • adaptar código sencillo;
    • entender qué hace tu script.

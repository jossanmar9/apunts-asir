    UT1 · Introducción a Python¶

    Esta página reúne toda la teoría de la UT1. La tabla de contenidos permite saltar a cada apartado 1.1–1.5 y a sus subapartados.

    UT1 · 1.1 Introducción a la programación y a Python¶

    Qué debes aprender¶

    En este tema hay que entender qué significa programar, por qué utilizamos lenguajes de programación, qué lugar ocupa Python y qué ocurre, de forma simplificada, cuando ejecutamos un programa.

    Programar consiste en dar instrucciones a un ordenador para resolver una tarea. Esas instrucciones deben ser precisas: el ordenador no interpreta ambigüedades como una persona.

    Idea clave

    Aprender a programar no consiste en memorizar órdenes. Consiste en aprender a resolver problemas paso a paso.

    Pensar antes de escribir código¶

    Si queremos calcular el precio final de un producto con IVA, primero podemos expresar el algoritmo:

    1. Conocer el precio sin IVA.
    2. Calcular el IVA.
    3. Sumarlo al precio inicial.
    4. Mostrar el resultado.
    precio = 100
iva = precio * 0.21
precio_final = precio + iva
print(precio_final)

    Lo importante no es solo conocer print(): debes poder explicar qué datos tienes, qué operación haces y qué resultado obtienes.

    Lenguajes de alto y bajo nivel¶

    Los ordenadores ejecutan internamente instrucciones muy cercanas al código máquina. Para las personas resulta mucho más cómodo utilizar lenguajes de programación de nivel superior.

    Tipo Idea principal
    Código máquina Lo ejecuta directamente la CPU
    Ensamblador Muy cercano al procesador
    C Suele considerarse de nivel medio o intermedio
    Python Lenguaje de alto nivel, legible y expresivo

    Python permite escribir instrucciones bastante fáciles de entender:

    print("Hola, mundo")

    Código fuente, bytecode e intérprete¶

    Un programa Python se guarda normalmente en un archivo con extensión .py. Ese archivo contiene el código fuente.

    De forma simplificada, al ejecutarlo ocurre esto:

    1. Escribes el código fuente en un archivo .py.
    2. Python analiza el código.
    3. Genera una representación intermedia llamada bytecode.
    4. La máquina virtual de Python interpreta ese bytecode.

    Por eso se suele decir que Python es un lenguaje interpretado, aunque exista ese paso intermedio.

    código fuente (.py)
        ↓
     Python
        ↓
     bytecode
        ↓
máquina virtual de Python
        ↓
    ejecución

    No necesitas memorizar los detalles internos. Para el examen debes distinguir código fuente, bytecode e intérprete.

    Características de Python¶

    Python es:

    • legible;
    • de propósito general;
    • multiplataforma;
    • multiparadigma;
    • adecuado para scripts pequeños;
    • acompañado de una biblioteca estándar muy amplia;
    • utilizado tanto para aprender como profesionalmente.

    En ASIR nos interesa especialmente para automatizar tareas de administración: procesar logs, revisar archivos, consultar rutas, organizar carpetas o comprobar información del sistema.

    Legibilidad y simplicidad¶

    El Zen de Python reúne principios de estilo del lenguaje. En este nivel basta con recordar dos ideas:

    • lo simple suele ser mejor que lo complicado;
    • la legibilidad importa.

    Una solución que puedes explicar suele ser mejor que una solución rebuscada que solo funciona porque la has copiado.

    Primer programa¶

    print("Hola, mundo")

    print() muestra información por pantalla. El texto está entre comillas porque es una cadena (str).

    También podemos mostrar variables:

    nombre = "Ana"
edad = 20

print("Nombre:", nombre)
print("Edad:", edad)

    Salida:

    Nombre: Ana
Edad: 20

    Comentarios¶

    Los comentarios empiezan por # y Python no los ejecuta.

    ## Precio sin IVA
precio = 100

## Calculamos el precio final aplicando un IVA del 21 %
precio_final = precio * 1.21
print(precio_final)

    Un comentario debe aportar información. Evita repetir literalmente lo que ya dice una instrucción sencilla.

    Errores frecuentes¶

    Olvidar las comillas¶

    print(Hola)

    Python interpreta Hola como el nombre de una variable. Si no existe, aparece un error.

    print("Hola")

    Confundir mayúsculas y minúsculas¶

    Python distingue mayúsculas de minúsculas:

    Print("Hola")  # Incorrecto
print("Hola")  # Correcto

    No leer el mensaje de error¶

    Cuando Python falla, normalmente indica el archivo, una línea aproximada, el tipo de error y una explicación. El error es información útil para localizar el problema.

    Ejemplo explicado¶

    Queremos calcular cuántos minutos tardaremos en leer 840 palabras a un ritmo de 140 palabras por minuto.

    palabras = 840
ritmo = 140
minutos = palabras / ritmo
print(minutos)

    Resultado:

    6.0

    El razonamiento es:

    1. Tenemos 840 palabras.
    2. Leemos 140 por minuto.
    3. Dividimos 840 / 140.
    4. Obtenemos 6 minutos.

    Comprueba que sabes...¶

    • Explicar qué significa programar.
    • Entender que programar es resolver problemas paso a paso.
    • Distinguir código fuente, bytecode e intérprete.
    • Explicar por qué Python es un lenguaje de alto nivel.
    • Reconocer usos de Python relacionados con ASIR.
    • Escribir un primer print().
    • Utilizar comentarios sencillos.
    • Entender que Python distingue mayúsculas y minúsculas.

    Para el examen

    Si te dan un problema sencillo, intenta explicar primero entrada → proceso → salida y después escribe el código.

    UT1 · 1.2 Entorno de desarrollo¶

    Qué debes aprender¶

    Para programar no basta con conocer la sintaxis de Python. Necesitamos herramientas para escribir, ejecutar, probar y depurar programas.

    Editor, IDE y terminal¶

    Un entorno de desarrollo puede incluir:

    • resaltado de sintaxis;
    • autocompletado;
    • ejecución de programas;
    • depuración paso a paso;
    • explorador de archivos;
    • integración con Git;
    • extensiones.
    Herramienta Uso habitual
    Thonny Entorno sencillo para empezar
    Visual Studio Code Editor profesional, flexible y extensible
    PyCharm IDE especializado en Python
    Jupyter Notebook Cuadernos con texto, código y resultados
    Anaconda Distribución utilizada especialmente en ciencia de datos

    En el módulo se utiliza principalmente VS Code, porque permite trabajar con Python, terminal, Git, extensiones y repositorios en un entorno parecido al profesional.

    Comprobar Python¶

    Desde una terminal:

    python --version

    En sistemas donde el comando es python3:

    python3 --version

    Si aparece una versión de Python, el intérprete está disponible.

    Ejecutar un archivo .py¶

    Si tenemos programa.py:

    python programa.py

    O, según el sistema:

    python3 programa.py

    También puede ejecutarse desde VS Code. El editor sirve para escribir el archivo; el intérprete de Python es quien ejecuta el código.

    Extensiones útiles de VS Code¶

    El material de clase destaca:

    • Python;
    • Pylance;
    • Ruff;
    • extensiones para Markdown.

    No hace falta dominar todas desde el principio. Lo esencial es saber crear un .py, ejecutarlo y leer los errores.

    Entornos virtuales¶

    Un entorno virtual permite aislar las librerías de un proyecto de las de otros proyectos.

    Crear uno:

    python -m venv .venv

    Activarlo en Linux/macOS:

    source .venv/bin/activate

    En PowerShell:

    .venv\Scripts\Activate.ps1

    Cuando está activo, los paquetes instalados quedan asociados a ese entorno.

    No confundas

    Un entorno virtual de Python no es una máquina virtual. Su objetivo es separar intérprete/dependencias del proyecto, no virtualizar un sistema operativo completo.

    pip, uv y pyenv¶

    pip es la herramienta clásica para instalar paquetes:

    pip install requests

    Una forma útil de asegurarte de que utilizas el pip asociado al Python actual es:

    python -m pip install requests

    El temario también presenta otras herramientas que debes reconocer:

    • uv: gestión rápida de paquetes y entornos;
    • pyenv: permite gestionar distintas versiones de Python;
    • pyenv-virtualenv: combina versiones y entornos virtuales;
    • Anaconda: distribución con muchas herramientas científicas preinstaladas.

    No es necesario dominar estas herramientas ahora: debes saber para qué sirven.

    Depuración¶

    Depurar significa ejecutar y observar un programa para entender qué ocurre.

    En VS Code puedes colocar un breakpoint o punto de interrupción. Cuando la ejecución se detiene puedes observar:

    • VARIABLES: valores existentes en ese momento;
    • WATCH: expresiones que quieres vigilar.

    El resaltado durante la depuración suele indicar la siguiente línea que se ejecutará.

    También existe pdb:

    import pdb

nombre = "Ana"
pdb.set_trace()
print(nombre)

    En este nivel basta con reconocer que depurar es observar el programa paso a paso, no cambiar cosas al azar hasta que funcione.

    Jupyter Notebook¶

    Jupyter permite mezclar en un mismo documento:

    • texto;
    • código;
    • resultados;
    • gráficos;
    • explicaciones.

    Es muy útil en análisis de datos y enseñanza. En el módulo se priorizan archivos .py para practicar un flujo de desarrollo convencional.

    Entornos online¶

    El material también menciona plataformas como Replit, que permiten programar desde el navegador. Son útiles para pruebas rápidas, aunque el entorno principal del módulo es local con VS Code.

    Organización del proyecto¶

    Una estructura sencilla puede ser:

    mi-proyecto-python/
├── README.md
├── ejercicios/
│   ├── ejercicio_01.py
│   └── ejercicio_02.py
└── pruebas/

    Organizar los archivos desde el principio evita terminar con decenas de scripts mezclados sin saber para qué sirve cada uno.

    Ejemplo práctico¶

    mkdir practica-python
cd practica-python
python3 -m venv .venv
source .venv/bin/activate
python --version

    Después creamos hola.py:

    print("Entorno preparado")

    Y ejecutamos:

    python hola.py

    Comprueba que sabes...¶

    • Explicar qué es un entorno de desarrollo.
    • Diferenciar editor, IDE, terminal e intérprete.
    • Reconocer VS Code, Thonny, PyCharm, Jupyter y Anaconda.
    • Comprobar la versión de Python.
    • Ejecutar un archivo .py.
    • Explicar para qué sirve un entorno virtual.
    • Saber que pip instala paquetes.
    • Reconocer uv, pyenv y pdb.
    • Explicar qué es un breakpoint y para qué sirven VARIABLES y WATCH.

    Para el examen

    Recuerda especialmente la diferencia entre escribir código (editor), ejecutarlo (intérprete) y aislar dependencias (entorno virtual).

    UT1 · 1.3 Datos, variables, tipos y objetos¶

    Qué debes aprender¶

    En Python trabajamos constantemente con datos. Cada dato tiene un tipo, y utilizamos variables para poder referirnos a esos datos durante el programa.

    Datos y tipos¶

    Un dato es una pieza de información que el programa puede manejar:

    42
"Ana"
3.14
True

    Podemos consultar el tipo con type():

    print(type(42))      # <class 'int'>
print(type("Ana"))   # <class 'str'>
print(type(3.14))    # <class 'float'>
print(type(True))    # <class 'bool'>

    Tipos básicos del tema:

    Tipo Ejemplo Uso
    int 10 Enteros
    float 3.5 Decimales
    str "hola" Texto
    bool True Verdadero/falso
    complex 3+5j Números complejos

    En Python todo son objetos¶

    Una idea básica del temario es que en Python los datos son objetos. De momento basta con pensar que un objeto tiene:

    • un tipo;
    • un valor;
    • una identidad.
    texto = "python"
print(type(texto))
print(texto.upper())

    No necesitas dominar todavía la programación orientada a objetos para entender esta idea.

    Variables¶

    Una variable es un nombre que apunta a un dato.

    nombre = "Ana"
edad = 20

    En:

    num_items = 10

    num_items es el nombre y 10 es el valor al que queda asociado.

    Lado izquierdo y lado derecho¶

    precio = 50 + 10

    Primero se evalúa 50 + 10 y después el resultado se asigna a precio.

    En algunos textos verás:

    • LHS (left-hand side): lado izquierdo de la asignación;
    • RHS (right-hand side): lado derecho que se evalúa.

    Nombres de variables¶

    Un nombre puede contener letras, números y guiones bajos, pero no puede comenzar por un número.

    Correcto:

    edad = 20
nombre_alumno = "Ana"
precio2 = 15.5

    Incorrecto:

    2precio = 10
nombre-alumno = "Ana"
class = "ASIR"

    Buenas prácticas:

    • nombres claros;
    • minúsculas y guiones bajos;
    • evitar abreviaturas que no aporten claridad;
    • no utilizar como variable nombres de funciones como type, input, list o str.

    Constantes¶

    Python no impide modificar una constante, pero por convenio escribimos en mayúsculas los valores que no deberían cambiar:

    IVA = 0.21
MAX_INTENTOS = 3

    Es una convención, no una protección del lenguaje.

    Asignación múltiple¶

    Python permite asignar varios valores a la vez:

    nombre, edad = "Ana", 20

    También el mismo objeto a varios nombres:

    a = b = c = 0

    Con objetos mutables hay que tener cuidado porque varios nombres pueden apuntar al mismo objeto.

    Identidad: id()¶

    id() devuelve un identificador asociado al objeto durante la ejecución:

    x = [1, 2, 3]
y = x

print(id(x))
print(id(y))

    Si ambos nombres apuntan al mismo objeto, sus cambios se comparten:

    x = [1, 2, 3]
y = x
y.append(4)

print(x)  # [1, 2, 3, 4]

    Mutabilidad¶

    Un objeto mutable puede cambiar después de crearse. Por ejemplo, una lista:

    numeros = [1, 2, 3]
numeros.append(4)
print(numeros)

    Los enteros, flotantes, booleanos, cadenas y tuplas son inmutables.

    texto = "hola"
## texto[0] = "H"  # Error

    Para obtener otro texto creamos una cadena nueva:

    texto = "hola"
texto = "H" + texto[1:]
print(texto)

    Ayuda integrada¶

    Puedes consultar ayuda desde Python:

    help(print)
help(str)

    Y comprobar tipos:

    valor = "10"
print(type(valor))

    Ejemplo explicado¶

    cantidad = 4
otra = cantidad
cantidad = cantidad + 2

print(cantidad)
print(otra)

    Salida:

    6
4

    otra quedó asociada al valor anterior. La instrucción cantidad = cantidad + 2 calcula un resultado nuevo y vuelve a asociar el nombre cantidad.

    Comprueba que sabes...¶

    • Reconocer int, float, str, bool y complex.
    • Utilizar type().
    • Explicar qué es una variable.
    • Distinguir nombre, valor y asignación.
    • Crear nombres de variables válidos.
    • Explicar la convención de las constantes.

    UT1 · 1.4 Números, booleanos y operadores¶

    Booleanos¶

    Un booleano solo puede tener dos valores:

    True
False

    Se escriben con la primera letra en mayúscula.

    activo = True

    Esto es incorrecto:

    activo = true

    Los booleanos representan condiciones: activo/inactivo, existe/no existe, aprobado/no aprobado.

    En operaciones numéricas Python trata True como 1 y False como 0:

    print(True + 3)   # 4
print(False + 3)  # 3

    No es una técnica que necesitemos utilizar habitualmente, pero ayuda a entender el tipo bool.

    Enteros: int¶

    edad = 20
saldo = -50

    Los guiones bajos pueden mejorar la lectura de números grandes:

    poblacion = 47_000_000

    No se puede escribir un entero decimal con un cero inicial:

    numero = 08  # Error de sintaxis

    Bases numéricas¶

    binario = 0b1010   # 10
octal = 0o12       # 10
hexadecimal = 0xA  # 10

    Los prefijos indican cómo está escrito el número; el valor sigue siendo numérico.

    Flotantes: float¶

    precio = 19.99
temperatura = -3.5

    También existe notación científica:

    valor = 0.4e1
print(valor)  # 4.0

    Si mezclamos un entero y un flotante, el resultado suele ser flotante:

    resultado = 3 + 2.5
print(resultado)       # 5.5
print(type(resultado)) # <class 'float'>

    Operadores aritméticos¶

    Operador Significado Ejemplo Resultado
    + suma 3 + 2 5
    - resta 3 - 2 1
    * multiplicación 3 * 2 6
    / división real 9 / 2 4.5
    // división entera 9 // 2 4
    % resto 9 % 4 1
    ** potencia 2 ** 3 8

    Cociente y resto¶

    minutos_totales = 1000
horas = minutos_totales // 60
minutos = minutos_totales % 60
print(horas, minutos)  # 16 40

    // obtiene grupos completos y % lo que sobra.

    Potencias y raíces¶

    cateto1 = 3
cateto2 = 4
hipotenusa = (cateto1 ** 2 + cateto2 ** 2) ** 0.5
print(hipotenusa)  # 5.0

    También podemos utilizar exponentes fraccionarios:

    numero = 27
raiz_cubica = numero ** (1 / 3)
print(raiz_cubica)  # 3.0

    División por cero¶

    print(10 / 0)

    Produce ZeroDivisionError.

    Prioridad de operadores¶

    Los paréntesis permiten indicar claramente qué debe calcularse primero.

    print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20

    De forma simplificada para este nivel:

    1. paréntesis;
    2. potencia **;
    3. multiplicación, divisiones y resto;
    4. suma y resta.

    Si tienes dudas, utiliza paréntesis para hacer explícita tu intención.

    Asignación aumentada¶

    x = x + 3

    Puede escribirse:

    x += 3

    También existen:

    x -= 1
x *= 2
x /= 4
x //= 2
x %= 3

    Funciones numéricas útiles¶

    print(abs(-7))          # 7
print(round(3.1416, 2)) # 3.14
print(int(3.9))         # 3
print(float("3.5"))     # 3.5

    int() no redondea

    int(3.9) devuelve 3. Para redondear utilizamos round().

    Comparaciones¶

    Las comparaciones producen booleanos:

    edad = 18
print(edad >= 18)  # True
print(edad < 18)   # False
    Operador Significado
    == igual
    != distinto
    < menor
    <= menor o igual
    > mayor
    >= mayor o igual

    No confundas asignación y comparación:

    edad = 18   # asigna
edad == 18  # compara

    Ejemplo explicado¶

    Queremos saber cuántas cajas completas podemos llenar con 29 piezas si caben 8 por caja y cuántas sobran.

    piezas = 29
capacidad = 8

cajas_completas = piezas // capacidad
sobrantes = piezas % capacidad

print(cajas_completas)
print(sobrantes)

    Resultado:

    3
5

    Comprueba que sabes...¶

    • Utilizar True y False correctamente.
    • Reconocer int y float.
    • Leer números binarios, octales y hexadecimales sencillos.
    • Utilizar +, -, *, /, //, % y **.
    • Explicar la diferencia entre / y //.
    • Utilizar cociente y resto en un problema.
    • Entender la prioridad de operadores.
    • Entender x += 3.
    • Utilizar abs(), round(), int() y float().
    • Reconocer una división por cero.
    • Diferenciar = de ==.
    • Utilizar operadores de comparación.

    UT1 · 1.5 Cadenas, entrada/salida y f-strings¶

    Cadenas de texto¶

    Las cadenas (str) permiten trabajar con nombres, mensajes, rutas, líneas de archivos, comandos y textos introducidos por el usuario.

    Podemos utilizar comillas simples o dobles:

    nombre = 'Ana'
mensaje = "Hola"

    Ambas formas son válidas. Conviene ser consistente.

    Cadenas multilínea¶

    texto = """Primera línea
Segunda línea
Tercera línea"""

    Las triples comillas también se utilizan en docstrings para documentar funciones y otros elementos de Python.

    Cadena vacía¶

    vacia = ""

    Es una cadena válida con longitud 0.

    Unicode¶

    Python 3 utiliza Unicode para representar texto:

    texto = "áéíóú ñ 中文"
print(texto)

    Cada carácter tiene un código numérico. Podemos consultar y convertir códigos con:

    print(ord("A"))  # 65
print(chr(65))   # A

    Conversión de tipos¶

    numero = 10
texto = str(numero)

    Y de texto a número:

    edad = int("20")
precio = float("3.50")

    La cadena debe representar un valor válido:

    float("3.1a")  # ValueError

    int() también permite indicar la base:

    print(int("1010", 2))  # 10

    Caracteres de escape¶

    Secuencia Significado
    \n salto de línea
    \t tabulación
    \\ barra invertida
    \" comilla doble

    Ejemplo:

    print("abc\ndef")

    Salida:

    abc
def

    Mostrar información con print()¶

    nombre = "Ana"
edad = 20
print(nombre, edad)

    Por defecto, print() separa los argumentos con espacios.

    sep¶

    print("Ana", "20", "ASIR", sep=";")

    Salida:

    Ana;20;ASIR

    end¶

    print("Hola", end=" ")
print("Ana")

    Salida:

    Hola Ana

    Pedir información con input()¶

    input() siempre devuelve una cadena de texto.

    nombre = input("Nombre: ")
print("Hola", nombre)

    Aunque el usuario escriba un número:

    edad = input("Edad: ")
print(type(edad))  # <class 'str'>

    Para calcular con ese dato debemos convertirlo:

    edad = int(input("Edad: "))
print(edad + 1)

    No utilices input como nombre de variable:

    input = "Ana"  # Mala práctica

    Estarías ocultando la función input().

    Operaciones con cadenas¶

    Concatenar¶

    saludo = "Hola" + " " + "Ana"
print(saludo)

    Repetir¶

    print("Wow" * 3)  # WowWowWow

    Longitud¶

    print(len("Hola"))  # 4

    Pertenencia con in¶

    frase = "Hola, Ana"
print("Ana" in frase)   # True
print("Luis" in frase)  # False

    Índices¶

    Las posiciones comienzan en 0:

    texto = "Python"
print(texto[0])   # P
print(texto[1])   # y
print(texto[-1])  # n

    Los índices negativos cuentan desde el final.

    Slicing o troceado¶

    La forma básica es [inicio:fin]. El índice final no se incluye.

    texto = "Python"
print(texto[0:2])  # Py
print(texto[2:])   # thon
print(texto[:4])   # Pyth

    Las cadenas son inmutables¶

    No podemos modificar directamente un carácter:

    texto = "python"
## texto[0] = "P"  # Error

    Creamos una cadena nueva:

    texto = "python"
texto = "P" + texto[1:]
print(texto)  # Python

    F-strings¶

    Las f-strings permiten combinar texto, variables y expresiones de forma legible.

    nombre = "Ana"
edad = 20
print(f"{nombre} tiene {edad} años")

    Salida:

    Ana tiene 20 años

    Si olvidamos la f:

    print("{nombre} tiene {edad} años")

    Python mostrará las llaves literalmente.

    Expresiones dentro de una f-string¶

    a = 5
b = 3
print(f"La suma es {a + b}")

    Mostrar llaves literales¶

    valor = 10
print(f"El diccionario es {{'valor': {valor}}}")

    Formatear decimales¶

    precio = 19.995
print(f"Precio final: {precio:.2f} €")

    .2f muestra el valor con dos decimales.

    numero = 3.14159265
print(f"{numero:.3f}")  # 3.142

    El formato cambia cómo se muestra el valor, no el valor original de la variable.

    Ejemplo explicado¶

    nombre = input("Nombre: ")
edad = int(input("Edad: "))

print(f"Hola, {nombre}")
print(f"El año que viene tendrás {edad + 1} años")

    Si introducimos Jose y 36:

    1. input() devuelve "Jose".
    2. El segundo input() devuelve inicialmente "36".
    3. int() lo convierte en el entero 36.
    4. La f-string calcula edad + 1.
    5. Se muestra 37 dentro del mensaje.

    • Crear cadenas con comillas simples, dobles y triples.
    • Reconocer una cadena vacía.
    • Entender que Python 3 utiliza Unicode.
    • Utilizar ord() y chr().
    • Convertir con str(), int() y float().
    • Reconocer un ValueError por conversión inválida.
    • Utilizar \n, \t, \\ y \".
    • Utilizar print() con sep y end.
    • Explicar que input() siempre devuelve str.
    • Concatenar y repetir cadenas.
    • Utilizar len() e in.
    • Acceder mediante índices positivos y negativos.
    • Utilizar slicing básico.
    • Explicar por qué una cadena es inmutable.
    • Crear f-strings con variables y expresiones.
    • Formatear decimales con .2f.

    1.1 · Introducción a Python¶

    Ejercicio 1 · Calcular un precio con IVA¶

    Enunciado. Calcula el precio final de un producto de 80 € aplicando un 21 % de IVA.

    precio = 80
iva = precio * 0.21
total = precio + iva
print(total)

    Paso a paso: precio = 80 guarda el dato inicial; precio * 0.21 calcula el 21 %; total suma precio e impuesto; print() muestra 96.8. Entrada: 80. Proceso: multiplicar y sumar. Salida: 96.8.

    palabras = 1200
ritmo = 150
minutos = palabras / ritmo
print(minutos)
    palabras y ritmo son los datos. / realiza una división real. El resultado 8.0 se guarda en minutos y después se muestra.

    1.3 · Variables y tipos de datos¶

    Ejercicio 1 · Identificar tipos¶

    usuario = "jose"
intentos = 3
espacio = 18.5
activo = True
print(type(usuario), type(intentos), type(espacio), type(activo))
    str representa texto, int enteros, float números con decimales y bool valores lógicos. type() permite comprobar el tipo real de cada objeto.

    Ejercicio 2 · Conversión de texto a número¶

    edad_texto = "36"

    "36" es texto y no debe sumarse directamente a 1. int() crea el entero 36; después la suma produce 37.

    a = 10
b = 20
a, b = b, a
print(a, b)
    Python evalúa primero los valores de la derecha y después los asigna a la izquierda. El resultado es 20 10.

    Ejercicio 1 · Cociente y resto¶

    segundos = 367

resto = segundos % 60
print(minutos, resto)
    // obtiene el cociente entero (6) y % el resto (7). Por tanto, 367 segundos son 6 minutos y 7 segundos.

    Ejercicio 2 · Potencia¶

    lado = 5
area = lado ** 2

    ** es el operador de potencia. 5 ** 2 equivale a 5 × 5 y produce 25.

    Ejercicio 3 · Prioridad de operadores¶

    Los paréntesis obligan a calcular primero 10 + 2; después se multiplica por 3. El resultado es 36. Sin paréntesis sería 16.

    Ejercicio 1 · Pedir el nombre¶

    Cada input() devuelve texto; int() lo convierte a entero. Solo después a + b realiza una suma numérica.

print(usuario[0])

    len() devuelve 5 caracteres; [0] accede al primero (a) y [-1] al último (n). Los índices empiezan en cero.

    UT2 · Objetos predefinidos y cadenas¶

    Esta página reúne toda la teoría de la UT2. La tabla de contenidos permite saltar a cada apartado 2.1–2.3 y a sus subapartados.

    UT2 · 2.1 Objetos predefinidos, funciones y métodos¶

    Qué debes entender¶

    En Python trabajamos con objetos. Un entero, una cadena o una lista son objetos y cada objeto tiene un tipo que determina qué operaciones podemos realizar con él.

    nombre = "Ana"
edad = 20

print(type(nombre))  # <class 'str'>
print(type(edad))    # <class 'int'>

    Esta unidad no pretende que estudies todavía programación orientada a objetos. Lo importante es reconocer qué objeto tienes y distinguir entre funciones, métodos y atributos.

    Funciones predefinidas¶

    Python incluye funciones que podemos utilizar directamente.

    texto = "Python"

print(len(texto))
print(type(texto))
print(id(texto))
    • len() devuelve la longitud.
    • type() indica el tipo del objeto.
    • id() devuelve un identificador asociado al objeto durante la ejecución.

    Una función recibe el objeto como argumento:

    len(texto)

    Métodos¶

    Un método es una operación asociada a un objeto. Se escribe después del objeto y de un punto:

    texto = "python"
print(texto.upper())

    Aquí upper() es un método del objeto texto.

    La diferencia visual es importante:

    len(texto)       # función
texto.upper()    # método

    No olvides los paréntesis

    texto.upper hace referencia al método, pero texto.upper() lo ejecuta.

    Atributos¶

    Un atributo representa información asociada a un objeto. A diferencia de un método, normalmente no lleva paréntesis.

    Más adelante encontrarás ejemplos como:

    ruta.name

    name es un atributo. En cambio:

    texto.upper()

    upper() es un método.

    Los tipos determinan las operaciones posibles¶

    No todos los objetos admiten las mismas operaciones.

    texto = "hola"
numero = 10

print(texto.upper())
print(numero + 5)

    No tendría sentido utilizar upper() sobre un entero.

    numero = 10
## numero.upper()  # AttributeError

    Cuando Python indica que un objeto no tiene determinado atributo o método, comprueba primero su tipo.

    Mutabilidad e inmutabilidad¶

    Ya vimos en UT1 que algunos objetos pueden modificarse y otros no.

    Las cadenas son inmutables. Sus métodos no cambian la cadena original: producen otra cadena.

    texto = "python"
mayusculas = texto.upper()

print(texto)       # python
print(mayusculas)  # PYTHON

    También puedes reasignar el resultado:

    texto = texto.upper()

    Ahora el nombre texto queda asociado al nuevo valor.

    Encadenar métodos¶

    Cuando un método devuelve un objeto que admite otro método, podemos encadenarlos.

    entrada = "  Python  "
resultado = entrada.strip().lower()
print(resultado)

    Salida:

    python

    Se ejecuta primero strip() y sobre el resultado se ejecuta lower().

    Para estudiar, si una expresión encadenada te confunde, sepárala:

    entrada = "  Python  "
limpia = entrada.strip()
resultado = limpia.lower()

    Consultar ayuda¶

    Python permite consultar documentación desde el propio intérprete:

    help(str)
help(len)
help(str.upper)

    También puedes utilizar dir() para observar los nombres disponibles en un objeto:

    texto = "hola"
print(dir(texto))

    No necesitas memorizar la salida de dir(). Sirve para explorar qué operaciones ofrece un objeto.

    Ejemplo explicado¶

    Queremos limpiar una respuesta introducida por un usuario y comprobar su longitud.

    respuesta = "  SI  "
limpia = respuesta.strip().lower()
longitud = len(limpia)

print(limpia)
print(longitud)
print(type(limpia))

    Resultado:

    si
2
<class 'str'>

    Paso a paso:

    1. respuesta es una cadena.
    2. strip() devuelve otra cadena sin los espacios exteriores.
    3. lower() devuelve otra cadena en minúsculas.
    4. len() recibe esa cadena y devuelve un entero.
    5. type() permite comprobar el tipo del resultado.

    Errores frecuentes¶

    Confundir método y función¶

    Incorrecto:

    ## texto.len()

    Correcto:

    len(texto)

    Olvidar guardar el resultado¶

    texto = "  hola  "
texto.strip()
print(texto)

    texto sigue conteniendo los espacios. Si quieres conservar el resultado:

    texto = texto.strip()

    Utilizar un método que el tipo no tiene¶

    Si no sabes qué tipo contiene una variable:

    print(type(valor))

    Comprueba el tipo antes de intentar corregir el resto del programa.

    Comprueba que sabes...¶

    • Explicar de forma sencilla qué es un objeto en Python.
    • Utilizar type(), len() e id().
    • Diferenciar una función de un método.
    • Reconocer un atributo por su forma de acceso.
    • Entender que una cadena es inmutable.
    • Explicar por qué texto.upper() no modifica automáticamente texto.
    • Encadenar métodos sencillos.
    • Utilizar help() para consultar ayuda.
    • Reconocer un AttributeError causado por utilizar una operación que el objeto no ofrece.

    Para el examen

    Si ves funcion(objeto), piensa en una función. Si ves objeto.metodo(), piensa en un método. Antes de utilizar cualquiera de los dos, identifica qué tipo de objeto estás manejando.

    Fuente principal: material de clase Introducción a Python 2.1, consultado el 29/10/2026.

    UT2 · 2.2 Métodos y operaciones con cadenas¶

    Las cadenas son secuencias¶

    Una cadena (str) es una secuencia de caracteres. Podemos consultar su longitud, acceder a posiciones y extraer fragmentos.

    texto = "Python"

print(len(texto))  # 6
print(texto[0])    # P
print(texto[-1])   # n

    Los índices empiezan en 0. Los índices negativos cuentan desde el final.

    Texto:   P  y  t  h  o  n
Índice:  0  1  2  3  4  5
Final:  -6 -5 -4 -3 -2 -1

    Slicing: extraer fragmentos¶

    La forma general es:

    texto[inicio:fin:paso]

    El carácter situado en inicio se incluye y el situado en fin no.

    texto = "Python"

print(texto[0:2])  # Py
print(texto[2:])   # thon
print(texto[:4])   # Pyth
print(texto[::2])  # Pto
print(texto[::-1]) # nohtyP

    Truco para el examen

    Si un slicing te cuesta, escribe debajo de la palabra los índices 0, 1, 2... y marca qué posiciones entran. Recuerda: el final queda fuera.

    Acceder a una posición que no existe produce IndexError:

    texto = "Python"
## print(texto[20])

    Un slicing, en cambio, puede superar el final sin producir ese error:

    print(texto[:20])  # Python

    Operadores con cadenas¶

    Concatenar¶

    nombre = "Ana"
saludo = "Hola " + nombre
print(saludo)

    Repetir¶

    print("-" * 10)

    Comprobar pertenencia¶

    frase = "servidor web"

print("web" in frase)      # True
print("linux" in frase)    # False
print("linux" not in frase) # True

    Si solo necesitas saber si aparece una subcadena, in suele ser más claro que buscar manualmente su posición.

    Eliminar espacios de los extremos¶

    texto = "  hola  "

print(texto.strip())
print(texto.lstrip())
print(texto.rstrip())
    • strip() limpia ambos extremos.
    • lstrip() limpia el izquierdo.
    • rstrip() limpia el derecho.

    No eliminan automáticamente los espacios interiores.

    Mayúsculas y minúsculas¶

    texto = "python para ASIR"

print(texto.lower())
print(texto.upper())
print(texto.capitalize())
print(texto.title())

    Estos métodos son especialmente útiles para normalizar una entrada:

    respuesta = input("¿Continuar? ").strip().lower()

    Así " SI " se transforma en "si".

    Buscar texto¶

    find()¶

    Devuelve la posición de la primera coincidencia o -1 si no encuentra el texto.

    texto = "servidor-web"

print(texto.find("web"))
print(texto.find("php"))  # -1

    No confundas posición 0 con ausencia

    Si el texto aparece al principio, find() devuelve 0. Si no aparece, devuelve -1.

    index()¶

    También busca una posición, pero si no encuentra el texto produce ValueError.

    texto = "servidor-web"
print(texto.index("web"))

    rfind()¶

    Busca desde la derecha y devuelve la posición de la última coincidencia.

    ruta = "docs/python/tema.md"
print(ruta.rfind("/"))

    Comprobar el principio o el final¶

    archivo = "informe.pdf"

print(archivo.startswith("informe"))  # True
print(archivo.endswith(".pdf"))       # True

    Son más claros que construir manualmente un slicing cuando la intención es precisamente comprobar el principio o el final.

    Contar coincidencias¶

    texto = "uno,dos,tres,cuatro"
print(texto.count(","))  # 3

    count() cuenta cuántas veces aparece una subcadena.

    Sustituir texto¶

    texto = "servidor viejo"
nuevo = texto.replace("viejo", "nuevo")
print(nuevo)

    Podemos limitar el número de sustituciones:

    texto = "error error error"
print(texto.replace("error", "aviso", 1))

    Resultado:

    aviso error error

    La cadena original no se modifica.

    Separar una cadena: split()¶

    registro = "ana;20;asir"
partes = registro.split(";")
print(partes)

    Resultado:

    ['ana', '20', 'asir']

    split() devuelve una lista de cadenas. El 20 sigue siendo texto.

    edad = int(partes[1])

    Sin argumento, split() separa por espacios en blanco:

    frase = "uno   dos  tres"
print(frase.split())

    Resultado:

    ['uno', 'dos', 'tres']

    Unir cadenas: join()¶

    join() realiza la operación contraria: reúne cadenas utilizando un separador.

    partes = ["ana", "20", "asir"]
resultado = " | ".join(partes)
print(resultado)

    Resultado:

    ana | 20 | asir

    La sintaxis puede parecer extraña al principio: el método se llama sobre el separador.

    " - ".join(partes)

    Los elementos que se unen deben ser cadenas.

    Métodos de comprobación¶

    print("Python".isalpha())
print("Python3".isalnum())
print("123".isdigit())
print("PYTHON".isupper())
print("python".islower())
    Método Comprueba
    isalpha() caracteres alfabéticos
    isalnum() letras o números
    isdigit() caracteres considerados dígitos
    isupper() letras en mayúsculas
    islower() letras en minúsculas

    isdigit() no valida cualquier número

    Por ejemplo, "-12".isdigit() y "3.5".isdigit() son False. Utilízalo solo cuando encaje con la regla que quieres comprobar.

    Ejemplo explicado: procesar un registro¶

    Tenemos:

      jose;asir;activo

    Queremos limpiar los extremos, separar los tres campos y mostrar el nombre en mayúsculas.

    registro = "  jose;asir;activo  "
registro = registro.strip()
partes = registro.split(";")

nombre = partes[0]
ciclo = partes[1]
estado = partes[2]

print(nombre.upper())
print(ciclo)
print(estado)

    Resultado:

    JOSE
asir
activo

    Antes de acceder a posiciones de una lista obtenida con split(), en un programa real conviene comprobar que la estructura recibida tiene los campos esperados. Aquí suponemos que el formato es correcto para centrarnos en las cadenas.

    Ejemplo explicado: extraer una extensión¶

    archivo = "copia.seguridad.tar.gz"
posicion = archivo.rfind(".")
extension = archivo[posicion + 1:]
print(extension)

    Resultado:

    gz

    rfind() localiza el último punto. Sumamos uno para que el punto no forme parte del slicing.

    Errores frecuentes¶

    Problema Causa probable
    IndexError Se ha accedido a una posición inexistente.
    ValueError con index() No existe la subcadena buscada.
    find() devuelve -1 La subcadena no aparece.
    strip() no elimina un espacio interior Solo actúa sobre los extremos.
    join() falla Algún elemento no es una cadena.
    El método parece no haber hecho nada No se guardó el nuevo resultado.

    Comprueba que sabes...¶

    • Utilizar índices positivos y negativos.
    • Explicar por qué el final de un slicing no se incluye.
    • Utilizar inicio:fin:paso.
    • Invertir una cadena con slicing.
    • Utilizar in y not in.
    • Utilizar strip(), lower() y upper().
    • Diferenciar find() e index().
    • Utilizar startswith() y endswith().
    • Utilizar count() y replace().
    • Separar texto con split().
    • Unir cadenas con join().
    • Reconocer qué comprueban isalpha(), isalnum() e isdigit().
    • Recordar que los métodos de cadenas devuelven nuevos resultados.

    Para el examen

    Los puntos que más conviene practicar son índices y slicing, find(), split(), join(), strip() y la diferencia entre modificar una variable y obtener una nueva cadena.

    Fuente principal: material de clase Introducción a Python 2.2, consultado el 29/10/2026.

    UT2 · 2.3 F-strings, formato y Unicode¶

    F-strings¶

    Las f-strings permiten construir cadenas introduciendo variables o expresiones directamente dentro del texto.

    nombre = "Ana"
edad = 20

print(f"{nombre} tiene {edad} años")

    La f antes de las comillas activa el formato y las expresiones se escriben entre {}.

    Si olvidas la f:

    print("{nombre} tiene {edad} años")

    se mostrarán las llaves y los nombres literalmente.

    Podemos incluir expresiones¶

    a = 5
b = 3
print(f"La suma es {a + b}")

    Resultado:

    La suma es 8

    Conviene mantener los cálculos importantes en variables cuando eso hace el programa más fácil de leer.

    precio = 50
iva = precio * 0.21
precio_final = precio + iva

print(f"Precio final: {precio_final} €")

    Formatear decimales¶

    precio = 19.995
print(f"Precio final: {precio:.2f} €")

    Resultado:

    Precio final: 20.00 €

    .2f indica que queremos mostrar dos decimales.

    Formatear no modifica el valor

    La variable precio sigue conteniendo su valor original. El formato afecta a cómo se representa dentro de esa cadena.

    numero = 3.14159265
print(f"{numero:.3f}")
print(numero)

    La primera línea muestra 3.142; la segunda sigue mostrando el valor original.

    Formatear enteros¶

    Podemos reservar una anchura y completar con ceros.

    codigo = 7
print(f"{codigo:03d}")

    Resultado:

    007

    03d significa, para este ejemplo, entero decimal con una anchura mínima de tres posiciones y ceros de relleno.

    Porcentajes¶

    completado = 0.375
print(f"Progreso: {completado:.1%}")

    Resultado:

    Progreso: 37.5%

    El formato % ya transforma la fracción para mostrarla como porcentaje. No multipliques previamente por 100 si vas a utilizar este formato.

    Alineación¶

    Las f-strings permiten alinear campos.

    print(f"{'Nombre':<10}{'Nota':>6}")
print(f"{'Ana':<10}{8:>6}")
print(f"{'Luis':<10}{10:>6}")
    • < alinea a la izquierda.
    • > alinea a la derecha.
    • ^ centra.

    El número indica una anchura mínima.

    print(f"{'ASIR':^10}")

    La alineación sirve para presentar información. No cambia los datos originales.

    Mostrar el nombre de una variable al depurar¶

    usuarios = 12
print(f"{usuarios=}")

    Resultado:

    usuarios=12

    Puede ser útil mientras investigas el valor de una variable.

    Mostrar llaves literalmente¶

    Dentro de una f-string, las llaves tienen un significado especial. Para mostrar una llave literal utilizamos dos:

    valor = 10
print(f"Valor: {{{valor}}}")

    Resultado:

    Valor: {10}

    Unicode¶

    Python 3 utiliza Unicode para representar texto. Esto permite trabajar directamente con caracteres de muchos idiomas.

    texto = "València · España · 中文 · Ω"
print(texto)

    No necesitamos tratar las letras acentuadas como un tipo especial de cadena.

    ord() y chr()¶

    ord() devuelve el punto de código de un carácter:

    print(ord("A"))

    chr() realiza la operación inversa:

    print(chr(65))

    Resultado:

    A

    Otro ejemplo:

    print(ord("Ω"))
print(chr(937))

    Comparación de cadenas¶

    Las cadenas distinguen mayúsculas y minúsculas.

    print("Python" == "python")  # False

    Si la regla de nuestro programa permite ignorar mayúsculas y espacios exteriores, podemos normalizar antes de comparar:

    respuesta = "  SI  "
respuesta = respuesta.strip().lower()
print(respuesta == "si")

    Resultado:

    True

    Normalizar no significa eliminar cualquier diferencia. Solo debemos transformar aquello que la regla del problema permita ignorar.

    Unicode y orden de texto¶

    Las comparaciones entre cadenas no equivalen necesariamente al orden alfabético que utilizaría una persona en un idioma concreto.

    print("Z" < "a")

    Python compara las secuencias de caracteres según su representación. Para este nivel es suficiente entender que mayúsculas, minúsculas y otros caracteres pueden producir resultados que no coincidan con una ordenación lingüística intuitiva.

    Ejemplo explicado: ficha de producto¶

    codigo = 8
producto = "disco SSD"
precio = 59.9
stock = 0.75

print(f"Código: P-{codigo:03d}")
print(f"Producto: {producto}")
print(f"Precio: {precio:.2f} €")
print(f"Stock objetivo: {stock:.0%}")

    Resultado:

    Código: P-008
Producto: disco SSD
Precio: 59.90 €
Stock objetivo: 75%

    Cada variable conserva su tipo. La f-string solo construye la representación final.

    Ejemplo explicado: tabla sencilla¶

    nombre1 = "Nginx"
puerto1 = 80
nombre2 = "MariaDB"
puerto2 = 3306

print(f"{'Servicio':<12}{'Puerto':>8}")
print(f"{nombre1:<12}{puerto1:>8d}")
print(f"{nombre2:<12}{puerto2:>8d}")

    El formato hace que las columnas sean más fáciles de leer. No es necesario convertir previamente los puertos a cadenas.

    Errores frecuentes¶

    Olvidar la f¶

    nombre = "Ana"
print("Hola {nombre}")

    Muestra las llaves literalmente.

    Aplicar un formato incompatible¶

    numero = "12"
## print(f"{numero:03d}")

    numero es una cadena, no un entero. Comprueba el tipo y convierte solo cuando tenga sentido.

    Confundir formato con cálculo¶

    precio = 3.14159
print(f"{precio:.2f}")

    Esto no reasigna precio ni modifica permanentemente su precisión.

    Multiplicar dos veces un porcentaje¶

    fraccion = 0.25
print(f"{fraccion:.0%}")  # 25%

    No necesitas hacer fraccion * 100 antes.

    Comprueba que sabes...¶

    • Crear una f-string.
    • Introducir variables y expresiones entre llaves.
    • Formatear un float con dos o tres decimales.
    • Formatear un entero con ceros iniciales.
    • Mostrar una fracción como porcentaje.
    • Alinear texto e enteros.
    • Explicar que el formato no cambia el valor original.
    • Mostrar llaves literales.
    • Entender que Python 3 trabaja con Unicode.
    • Utilizar ord() y chr().
    • Reconocer que las comparaciones distinguen mayúsculas y minúsculas.
    • Normalizar una entrada con strip().lower() cuando la regla del problema lo permita.

    Para el examen

    Separa siempre valor y presentación: calcula con números y aplica el formato cuando vayas a mostrarlos. Recuerda especialmente :.2f, :03d, :.1% y las alineaciones <, > y ^.

    Ejercicios resueltos paso a paso · UT2¶

    2.1 · Objetos predefinidos¶

    Ejercicio 1 · Operaciones con texto¶

    nombre = "Servidor Web"
print(len(nombre))
print(nombre[0])
    len() cuenta todos los caracteres, incluido el espacio. [0] obtiene el primer carácter porque los índices comienzan en cero.

    Ejercicio 2 · Cortar una cadena¶

    ip = "192.168.1.50"
print(ip[0:7])
    El slice [0:7] toma caracteres desde la posición 0 hasta antes de la 7. El límite final nunca se incluye.

    Ejercicio 3 · Pertenencia¶

    archivo = "backup.sql"
print(".sql" in archivo)
    in pregunta si una cadena aparece dentro de otra y devuelve un booleano. Aquí el resultado es True.

    2.2 · Métodos de cadenas¶

    Ejercicio 1 · Limpiar entrada¶

    usuario = "  ADMIN  "
usuario = usuario.strip().lower()
print(usuario)
    strip() elimina espacios exteriores. Sobre el resultado, lower() convierte a minúsculas. La salida es admin.

    Ejercicio 2 · Sustituir texto¶

    ruta = "datos\\usuarios\\lista.txt"
ruta = ruta.replace("\\", "/")
print(ruta)
    replace() crea una nueva cadena sustituyendo cada barra invertida por /. Las cadenas son inmutables: por eso reasignamos el resultado.

    Ejercicio 3 · Separar datos¶

    linea = "web01;192.168.1.10;activo"
datos = linea.split(";")
print(datos[0])
print(datos[1])
    split(";") divide el texto usando ; como separador y devuelve una lista. [0] y [1] acceden a sus dos primeros elementos.

    2.3 · f-strings y Unicode¶

    Ejercicio 1 · Informe con f-string¶

    host = "web01"
cpu = 37.456
print(f"{host}: CPU {cpu:.1f}%")
    La f permite insertar expresiones entre llaves. {cpu:.1f} muestra el número con un decimal: web01: CPU 37.5%.

    Ejercicio 2 · Alinear una tabla¶

    servicio = "nginx"
estado = "activo"
print(f"{servicio:<12}{estado:>10}")
    <12 reserva 12 posiciones y alinea a la izquierda; >10 reserva 10 y alinea a la derecha. Es útil para informes de terminal.

    Ejercicio 3 · Unicode¶

    mensaje = "Servidor ✓"
print(mensaje)
print(len(mensaje))
    Python 3 trabaja con Unicode. El símbolo ✓ forma parte de la cadena y len() cuenta caracteres, no los bytes usados para almacenarlos.

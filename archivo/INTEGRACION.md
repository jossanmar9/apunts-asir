# Archivo de los materiales originales

Estos archivos se conservan como referencia del repositorio. Están fuera de `docs/`, por lo que MkDocs no los publica ni los incorpora al índice de búsqueda. No hay enlaces a esta carpeta desde la web.

Las ampliaciones útiles se han redactado en castellano e integrado en los temas publicados. Se conservan los originales completos para no perder contenido que corresponde a unidades futuras. Los ejercicios antiguos no se han trasladado como soluciones de tareas de clase.

| Material anterior | Integración en los apuntes actuales |
| --- | --- |
| `bash/01` a `bash/03`, lectura y arrays | `docs/aso/02-bash-dades.md` y `03-bash-decisions.md` |
| Condicionales, bucles y funciones Bash | `docs/aso/03-bash-decisions.md` y `04-bash-bucles.md` |
| Redirecciones, texto, find y grep | `docs/aso/05-bash-text.md` |
| Robustez y método de resolución | `docs/aso/06-bash-errors.md` y guía de estudio |
| Docker: contenedores, imágenes, montajes, redes, Compose y Dockerfile | `docs/iaw/03-entorn.md` |
| PHP: tipos, lenguaje, formularios y sesiones | `docs/iaw/04-php.md` a `07-estat.md` |
| Python: entorno, datos, texto y control | `docs/python-classe/01-entorn.md` a `06-control.md` |
| Python: excepciones, archivos y sysadmin | `docs/python-classe/07-errors.md` y `08-biblioteques.md`, como ampliación contextual |
| Git: trabajo diario, remoto, ramas, PR, deshacer y casos prácticos | `docs/git-github/index.md` |
| Glosario: sistema, programación, web, Git, Docker y datos | Definiciones distribuidas en los 22 temas publicados |
| Chuletas | Tablas de consulta y recuadros de repaso dentro de los temas correspondientes |
| PowerShell, Active Directory, PDO/CRUD, POO y estructuras avanzadas | Originales conservados para las unidades correspondientes; no se presentan como teoría de clase ya publicada |

Las definiciones de contexto también se ubican donde ayudan a distinguir conceptos: LVM junto a almacenamiento de Docker, Active Directory junto a servicios y los términos relacionales junto a arquitectura y persistencia. Se definen sin presentar las unidades completas pendientes como teoría de clase ya publicada.

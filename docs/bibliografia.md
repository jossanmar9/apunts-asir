# Bibliografia

Estos apunts estan escrits a partir de l'estudi dels materials següents. Els textos i els exemples d'esta web són propis; si vols aprofundir, els originals són molt recomanables.

## Bash

- **Ignacio Pachés Giner** — *Guía de Bash scripting. Aprende a automatizar Linux desde cero.* Llicència CC BY-ND 4.0.
- **Ignacio Pachés Giner** — *Bash scripting. Nivel básico: ejercicios explicados paso a paso.*
- **Ignacio Pachés Giner** — *Bash scripting. Nivel moderado: ejercicios explicados paso a paso.*
- Manual oficial: `man bash` i [GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/).
- [ShellCheck](https://www.shellcheck.net/): analitzador d'errors en scripts.

## Python

- **Sergio Delgado Quintero** — *Aprende Python*. Disponible en línia en [aprendepython.es](https://aprendepython.es/).
- **José Miguel Ruiz Torres** — *Manual básico, iniciación a Python 3.* Llicència CC BY-NC-SA 3.0 ES.
- **Francisco J. Martínez Mimbrera i David Díaz Jiménez** — *Ejercicios básicos de programación resueltos en Python.* Universidad de Jaén, 2026. Llicència CC BY-NC-SA 4.0.
- Documentació oficial: [docs.python.org/es/3](https://docs.python.org/es/3/).

## PowerShell

- **P. Ruiz** — *Scripts en PowerShell: Guía para principiantes.* SomeBooks.es. Llicència CC BY-NC-ND 3.0. Disponible en línia en [somebooks.es](https://somebooks.es/scripts-powershell-guia-principiantes/).
- Documentació oficial: [learn.microsoft.com/powershell](https://learn.microsoft.com/es-es/powershell/).

## Docker

- **José Domingo Muñoz Rodríguez** — *Curso de Docker* (OpenWebinars, 2024). Llicència GPL-3.0. Disponible en [github.com/josedom24/curso_docker_ow](https://github.com/josedom24/curso_docker_ow).
- Documentació oficial: [docs.docker.com](https://docs.docker.com/) i les pàgines de cada imatge en [Docker Hub](https://hub.docker.com/).

## Git i GitHub

- **Scott Chacon i Ben Straub** — *Pro Git*. Llicència CC BY-NC-SA 3.0. Disponible en castellà en [git-scm.com/book/es](https://git-scm.com/book/es/v2).
- Documentació de GitHub: [docs.github.com/es](https://docs.github.com/es).

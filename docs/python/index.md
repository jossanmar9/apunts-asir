# Python

Python és un llenguatge fàcil de llegir i amb una biblioteca estàndard enorme. Per a un administrador de sistemes és el pas següent quan un script de Bash es fa massa llarg: tractar fitxers, processar logs, parlar amb APIs, automatitzar tasques...

!!! tip "Bash o Python?"
    **Bash** per a encadenar ordres del sistema en pocs passos. **Python** quan hi ha lògica, càlculs, estructures de dades o més de 50–100 línies. Molts scripts reals combinen tots dos.
